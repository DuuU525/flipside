# Flipside · P瓶子 — 抛瓶子

> a bottle-flip &amp; cap-collecting game

一个纯前端、零依赖的抛瓶子网页小游戏（45° 俯角 · 正对桌边版）。以时机技巧为核心、暗藏深度成长系统：在摆动的蓄力条上找准时机松手让瓶子直立或倒立站住，练出连击、攒下瓶盖，投入沙漏双方向科技树、自动抛瓶的「手」、稀有的黄金与翡翠瓶。

## 玩法

- **45° 俯角、相机正对桌边**（矩形桌面），桌面上散落着若干瓶子。
- **按住瓶子蓄力**：蓄力条上的白色指针来回摆动，**松手**时指针落在哪个区间就得到对应结果。
- 瓶子随机落点、随机正转/反转，最终状态由蓄力指针位置决定：

| 状态 | 判定 | 获得瓶盖 |
|---|---|---|
| 直立（底部站立） | 指针落在绿色「直立」区间 | `+1` |
| 倒立（瓶口站立） | 指针落在金色「倒立」区间 | `+5` |
| 平躺 | 指针落在其余区间 | `0`（连击清零） |

- 连击可叠加额外瓶盖（每次 `+1`），平躺清零。**连击有存在时间**：手动成功后连击进入倒计时窗口（基础 4 秒），窗口内未再成功则连击中断归零；「连击存在时间」科技可延长窗口（见科技树）。
- **稀有瓶**：黄金瓶（命中 ×2.5）/ 翡翠瓶（命中 ×5）通过宝箱首次开出解锁图鉴，之后可在道具页签直购，是长线收集目标。三种瓶子有不同「身份」：**玻璃=稳定**（基础）/ **黄金=幸运**（手动金色瞬间概率 +1%，挂机需手幸运 +0.2%）/ **翡翠=成长**（手动命中 3% 触发掉落，挂机需自动收获加速掉落）。
- **初始桌面无瓶子**：开局会掉一个教学宝箱，拾取后解锁玻璃瓶图鉴并获得第一个玻璃瓶；右侧「功能界面」初始锁定，消耗 **30 瓶盖**解锁。

## 功能界面（右侧面板）

解锁后出现三个页签：

### 道具页签
展示购买到的「拥有物」，有数量、可堆叠，消耗瓶盖购买。**瓶子类（玻璃/黄金/翡翠）靠图鉴收集解锁**，锤子/手靠科技解锁，宝箱始终可买；未解锁的道具不显示：

| 道具 | 效果 | 价格 | 可重复 |
|---|---|---|---|
| 玻璃瓶 | 桌面增加 1 个玻璃瓶（图鉴解锁） | 25 瓶盖 | 是（由桌面上限限制） |
| 黄金瓶 | 桌面增加 1 个黄金瓶 · 命中 ×2.5（图鉴解锁） | 150 瓶盖 | 是（由桌面上限限制） |
| 翡翠瓶 | 桌面增加 1 个翡翠瓶 · 命中 ×5（图鉴解锁） | 300 瓶盖 | 是（由桌面上限限制） |
| 手 | 自动抛空闲瓶子（每只手独立计时，需有空闲瓶子） | 60 瓶盖 | 是（上限 8 个） |
| 锤子 | 敲碎任意瓶子时消耗 1 个，返还 70% + 掉宝 | 30 瓶盖 | 是（消耗品，上限 99） |
| 神秘宝箱 | 随机开出玻璃瓶/瓶盖/锤子/黄金瓶/翡翠瓶 | 200 瓶盖 | 是（无上限） |

> **图鉴解锁瓶子**：黄金瓶（×2.5）/翡翠瓶（×5）/玻璃瓶首次开出（宝箱或掉落）即解锁购买权；开局教学宝箱固定开出玻璃瓶，拾取后解锁玻璃瓶图鉴。
> **神秘宝箱**是黄金瓶/翡翠瓶的**首要获取途径**——宝箱奖池：玻璃瓶 45% / 瓶盖 100（20%）/ 锤子 10% / 黄金瓶 20% / 翡翠瓶 5%，开箱结果直接结算（首次开出解锁图鉴 + 道具 +1）。

### 科技树页签
点击「科技树」页签会弹出**全屏科技树大图**（沙漏形布局：倒立瓶 A 向上 / 正立瓶 B 向下 / 瓶子在瓶口对接处）。科技树采用**科技点经济 + 双方向**结构，共 25 个节点。节点用方形徽章**仅展示图标**（名称、占点、详情均在悬浮提示 tooltip 中查看），三种状态一眼可辨（已解锁=绿色发光、可解锁=金色脉冲光圈、未解锁=灰色锁定），占点数显示在右上角角标：

**科技点经济**：科技不再直接花瓶盖，改为「瓶盖兑换科技点（通用池 50 上限）→ 节点花科技点解锁」。兑换价格随累计购买数几何递增（第 N 点 = `100 × 1.15^(N-1)`，第 1 点 100 盖、第 50 点约 33 万盖），一次花占点数即解锁满级（`maxLevel` 仅用于计算满级效果值）。

**沙漏双方向**（对称约束：A满=B满=35 点；50 = 基建 5 + 满方向 35 + 另一方向基础 10，两边都满需 75 点 → 取舍成立）：

- **特殊玩法（终极节点专属）**：倒立宗师解锁 Zoom 专注领域（手动连击 ≥20 几率进入，暗幕聚光只抛一个瓶子挑战，成功高额奖励）；自动化工厂解锁桌面奇妙事件（掉落瓶盖/瓶子/锤子到收获格子）。
- **重置方向**：科技树 footer「重置方向」按钮（红色）——方向节点（A/B）科技点全额退回、方向产物「手」清空不返还、中立基建保留、成就/里程碑不退回。
- 科技树采用**沙漏形布局**（`renderTech()`）：根节点在中心（瓶口对接处），方向 A 倒立瓶向上展开（深度越深越靠上、瓶身越宽），方向 B 正立瓶向下展开，中立基建在腰部左侧 tidy-tree。**只展示前置已满足的节点，前置未解锁的科技不显示，随解锁逐层揭示**。节点状态由 `techNodeState()` 判定（根节点映射解锁状态；已解锁/可解锁/锁定，锁定节点不渲染）；点击节点花科技点解锁（一次性满级），关闭按钮 ✕、点遮罩空白处或按 Esc 均可退出。
- 科技树视图支持**拖拽平移 + 滚轮缩放**：所有节点/连线包在 `<g id="techViewport">` 容器内（`transform = translate(x y) scale(s)`），按住左键（或触摸）拖拽平移、滚轮以鼠标为中心缩放（0.4×~3×），底部「重置视图」按钮复位。用 `getScreenCTM().inverse()` 做屏幕→用户坐标映射（自动处理 viewBox/preserveAspectRatio）；拖拽移动超过 5px 阈值后本次点击被抑制（`techSuppressClick`），避免拖拽误触节点解锁。
- 功能界面锁定时，侧边栏提供「查看科技树」按钮（`previewTechBtn`）可先查看科技树全貌，此时第 0 层「解锁科技树功能」呈金色可解锁，点击即解锁科技树。

 - **手**：自动抛瓶，**每只手独立计时**、独立抛空闲瓶子（间隔 = `4000 - 频率等级×500` 毫秒，手速强化里程碑再 ×0.8）。手越多、同时工作的手越多，总吞吐 = 手数 / 间隔；手多于瓶子时，多余的手因没有空闲瓶子而自然等待。手**不常驻桌面**：只在抛瓶瞬间以卡通手套出现在目标瓶子正上方，快速落下拍击（拍击瞬间才真正抛出瓶子），拍完上弹淡出、立即消失。
 - **手动 vs 挂机收益分层**：手抛瓶**不累计、不打断连击**（连击只属于手动抛瓶），且收益乘 `handMult`（默认 0.5）打折；手动抛瓶收益乘 `manualMult`（默认 1.5）。手抛瓶的漂浮文字带 `🤖` 标记，一眼可辨。这样手动=技巧爆发（连击+倍率）、挂机=稳定底薪（不吃连击、打折），避免挂机靠手数×频率反超手动。
- **提高手的几率**：每级让手抛瓶的直立/倒立区间各 +0.03，手更"准"。

## 技术说明

- **音效与音乐系统**（WebAudio 合成，无外部音频文件）：
  - 顶部 HUD 右侧「🔊」按钮打开声音设置浮层，分两栏：**音效**（音量滑块 + 静音开关）与**音乐**（音量滑块 + 开关），各自独立控制、实时生效。
  - 音效（SFX）音量通过 `Sound.setVolume / setEnabled` 控制；背景音乐（BGM）音量通过 `Music.setVolume / setEnabled` 控制。
  - 音效清单：抛瓶（上滑音）、直立成功（双音）、倒立（琶音）、平躺失败（低音）、购买/解锁（清脆上扬）、成就/里程碑（高亢琶音）、敲碎（低沉重击）。
  - **背景音乐**：一段 C 大调循环旋律（主旋律 triangle + 低音 sine，16 步 × 240ms ≈ 3.84 秒循环），由 `Music.start()/stop()` 控制——开始游戏时自动播放，点「重新开始」回到菜单时停止；音符频率/节奏在 `Music` 模块顶部的 `MELODY/BASS` 可调。
  - **音乐节奏与连击挂钩**：连击越高，音乐节奏越快、层次越丰富——每 1 连击每步缩短 4ms（基础 240ms，下限 140ms），连击 ≥5 加入低音、≥10 加入五度和声、≥15 加入 hi-hat 打击乐；节奏平滑趋近目标（`smoothFactor=0.2`），连击断掉时不会突变而是自然回落，并播放一段「断连下滑音」（sawtooth 从高频滑到低频，连击越高起始频率越高）。阈值与加速参数在 `CONFIG.musicStreak` 可调。
  - 音效与音乐设置分别持久化在 `pbottle.sound` 与 `pbottle.music`（`{ volume, enabled }`）。

- **45° 俯角侧视投影**（相机垂直于桌边，向下俯视 45°）：
  - 桌面是水平面，渲染成矩形（前边在后边下方，深度方向压缩 sin45°）。
  - 世界坐标 `(wx, wy)`：`wx` = 左右，`wy` = 前后（深度），`h` = 瓶子底部离桌面高度。
  - 屏幕坐标 `x = (wx-w/2)·scale`，`y = oy - (wy-d/2)·sin45°·scale - h·cos45°·scale`。
  - `project` 返回瓶子底部（脚点）的屏幕坐标，瓶子底部精确贴台面。
  - 桌子含墨蓝冰面（`#1f3d63→#0c1e38` 渐变）+ 前侧面厚度 + 后缘冷色高光 + 冰裂纹（固定种子随机，静态缓存只画一次）。
- **像素风渲染**（低分辨率缓冲 + 最近邻放大）：
  - 所有游戏图形（桌子/瓶子/阴影/手/蓄力条）先绘制到离屏低分辨率缓冲（`buf`，尺寸 = `worldW/PIXEL × worldH/PIXEL`，`PIXEL=4`，即 225×155），再用 `drawImage` 最近邻放大 4 倍到显示画布（`ui`），产生复古颗粒。
  - 文字（漂浮文字/蓄力条标签/敲碎提示/调试信息）绘制在显示画布 `ui` 上，保持原生分辨率清晰可读（中文不受低分辨率影响）。
  - `imageSmoothingEnabled=false` + CSS `image-rendering: pixelated` 保证像素颗粒不被平滑。
- **像素图标系统**（`js/pixel.js`，零依赖手绘）：
  - 全部 46 个图标（科技树节点 / 道具 / 成就 / 里程碑 / 每日目标 / 提示 / 音效 / 关闭等）均为手绘 16×16 像素网格（字符串矩阵，`.`=透明、其余字符映射到 `PX` 调色板），替换了原先的所有 emoji。
  - 三个渲染器：`svg()` 输出 crispEdges 内联 SVG（用于 DOM 卡片/按钮/提示）、`techNode()` 输出 SVG `<g>`（用于全屏科技树 1000×1000 viewBox）、`canvasIcon()` 用 fillRect 画到 canvas（敲碎提示的锤子、挂机抛瓶的机器人标记）。
  - 图标名集中在 `TECH_TREE` / `ACHIEVEMENTS` / `MILESTONES` / `DAILY_POOL` 的 `icon` 字段（如 `'bottle'` / `'crown'` / `'target'`）。
- **像素文字**：全局字体栈 `Courier New / SimSun(宋体) / NSimSun / monospace` + `-webkit-font-smoothing: none` 关闭抗锯齿——宋体在 Windows 小字号下呈点阵/位图效果，配合等宽西文字体形成复古像素字。canvas 上的浮动文字（"+N 瓶盖"）通过 `textSprite()` 先栅格化到低分辨率再最近邻放大 2 倍，让文字也带像素颗粒；蓄力条标签与敲碎提示直接用像素字体栈绘制。
- **像素风 UI（数字/外框/背景）**（`css/style.css`，全街机风）：
  - **数字**：HUD 统计、面板余额、成就统计等数字统一等宽像素字体 + `text-shadow: 2px 2px 0` 硬描边，形成像素浮雕。
  - **像素数字字体（`pixel.js` 的 `DIGITS` + `digits()`）**：游戏界面的核心数字（瓶盖数量/最佳/连击/次数、面板余额、解锁消耗、道具价格）不再用系统字体，而是渲染成手绘 3×5 经典街机七段式像素数字（内联 SVG `currentColor` + `crispEdges` + 最近邻放大），自带 `drop-shadow` 硬阴影；`insufficient` 状态因 `currentColor` 继承可正常变红闪烁。字符集含 0–9、`+`、`/`。
  - **外框**：全部 `border-radius` 归零（直角），面板/舞台/卡片/统计块加粗到 2px 描边，内衬 `inset` 浅线形成双层像素浮雕边框。
  - **硬阴影**：所有柔和 `box-shadow`（模糊阴影）替换为阶梯硬阴影（`x y 0`，无模糊），如 `box-shadow: 4px 4px 0 #06101f`。
  - **按钮**：主按钮/迷你按钮/声音按钮统一 2px 深色描边 + 硬阴影，按下时 `translate(4px,4px)` + 阴影归零，呈现像素风「下沉」手感。
  - **背景**：`radial-gradient` 换成纯色底 + `background-image` 双 `linear-gradient` 交叉的 10px 像素网格纹理；卡片/弹窗的 `linear-gradient` 全部换成纯色。
  - 科技树节点外框为方形 `<rect>`（街机风），Lv 角标为方形角标，脉冲光圈为方形放大动画。
- **街霸式连击提示（`drawCombo()`）**：手动抛瓶连击 ≥2 时，**右上角**弹出大字「COMBO + 数字」，字母与数字统一用 5×5 像素字模（`GLYPHS5` + `canvasText()`，风格一致不再混搭宋体）。动态效果：每次命中从 1.5× 弹回 1× 的缓出缩放、街霸斜体摆正（-7° 弹回 0°）、弹出瞬间左右微摆、持续轻微上下浮动、快速淡入，外加 3px 深色硬阴影。颜色随连击数升级（2–4 金 `#ffd166`、5–9 橙 `#ff9f43`、10–19 红 `#ff6b6b`、20+ 紫 `#c792ea`）。断连（平躺）时提示立即消失，配合断连下滑音。`window.__pbottle.combo(n)` 可调试触发。
- **蓄力条机制**（技能型玩法，替代纯随机）：
  - 按住瓶子进入蓄力，蓄力条底部显示，白色指针 `phase` 以 ping-pong 三角波来回摆动（`speed` 控制速度）。
  - 松手时由指针位置 `p` 判定结果：`|p - invertedCenter| ≤ invertedHalf` → 倒立；`|p - uprightCenter| ≤ uprightHalf` → 直立；否则平躺。
  - **倒立区间位置随机（方案 B）**：直立区间中心固定（`uprightCenter`，可肌肉记忆）；倒立区间中心**每次蓄力随机**（`randomInvertedCenter()`，约束窗口落在 `[0,1]` 内且与直立区间保持 `0.04` 间隔避免重叠/混淆）。这样直立=稳定的基础收益、倒立=需现场追踪的特殊奖励，两者技巧类型并存。
  - 区间越宽越容易命中，科技「稳定科技 / 平衡科技 / 神之一手」会扩宽直立/倒立区间。
  - 连击越高指针越快（`speedPerStreak`），形成风险递增的张力；平躺连击清零。
- **多种瓶子类型**：玻璃瓶（×1，蓝色）、黄金瓶（×2.5，金色光晕）、翡翠瓶（×5，绿色光晕）。三种瓶子均由「图鉴收集」解锁（首次开出即解锁购买权，玻璃瓶由开局教学宝箱解锁、黄金/翡翠瓶由宝箱开出），在道具页签购买。命中（直立/倒立）时按各自倍率奖励。**特殊效果**（身份差异化）：玻璃瓶=稳定（无额外效果）；黄金瓶=幸运（手动金色瞬间概率 +1%，挂机需「手幸运」+0.2%）；翡翠瓶=成长（手动命中 3% 触发掉落事件，挂机需「自动收获」手连成 +1）。
- **手自动抛瓶**：购买「手」后，**每只手独立计时**，每隔 `(4000 - 频率等级×500)` 毫秒自动抛一个空闲瓶子（结果用 `handRanges()` 判定），多只手并行工作。手可视化：手**不常驻桌面**——`rebuildHands()` 只按拥有数量创建手对象（含随机初始相位错开拍击），`slapWithHand()` 锁定目标瓶子的拍击点（`sx/sy/sLift`，瓶子飞走后手留在原地不跟随），`drawHand()` 仅在 `state === 'slap'` 时绘制（从瓶肩上方快速落下→拍击→上弹淡出，抛完回 `idle` 即消失），`drawHandFront()` 绘制正视图手套（袖口 + 手掌 + 手指 + 拇指）。
- **桌面上限**：`currentMaxBottles()` = `maxBottles`(8) + 瓶子科技等级 × 2，最高 20。瓶子生成时特殊瓶（黄金/翡翠）优先占位，玻璃瓶受剩余空间限制让位。
- **锤子敲碎**：科技树解锁「锤子」节点，再到道具页签购买**消耗品**（可堆叠，每次敲碎消耗 1 个，30 盖）。点锤子卡片「使用」进入敲碎模式（画布顶部出现提示），点**任意瓶子**敲碎：消耗 1 个锤子 + 永久减少对应瓶子道具拥有量 + 返还购买价 70%（返还恒低于瓶子价；退款不计入累计获得，避免刷财富成就）+ 有几率掉同类瓶(10%)，否则掉宝箱(2.5%)（互斥，一次最多掉一样）。初始玻璃瓶（免费瓶）可敲碎但不返还、不掉落；点空白或再次「使用」退出。
- **纯随机结果**（无物理模拟）：
  - 随机 `±1` 决定正转/反转。
  - 随机落点（桌面范围内）。
- 瓶子**始终以正视图（正面朝向镜头）**绘制（billboard），`rot` 即瓶口朝向角度：
  - 直立 `upright` = 0°（瓶口朝上，竖直瓶子）
  - 倒立 `inverted` = 180°（瓶口朝下，倒置瓶子）
  - 平躺 `lying` = 90° 或 270°（瓶口朝右/朝左，横躺瓶子，随机二选一）
- 瓶子整体缩放 `BOTTLE_SCALE=0.7`（全高 120→84px），同时缩放影子/命中中心/手拍击点，保持脚点精确贴地。
- 蓄力选中高亮：不再画圆圈，改为**瓶子轮廓脉冲描边**（`drawBottleFront` 的 `highlight` 参数，青色 `rgba(76,201,240)` 呼吸闪烁），贴合瓶身更像素风。
- 抛瓶动画：位置缓动 + 抛物线高度（`peakH·sin(πt)`）+ 旋转（终点 = 目标朝向 + 整数圈）。
- 渲染按深度排序（`wy` 降序，越靠前的瓶子越后画），保证前后遮挡正确。

## 调参

所有参数集中在 `js/data.js` 顶部的 `CONFIG` 对象：

| 参数 | 含义 |
|---|---|
| `bottleCount` | 初始免费瓶子数量（默认 0，首个玻璃瓶靠教学宝箱获得） |
| `maxBottles` | 桌面瓶子数量基础上限（=8，扩容科技在此之上叠加） |
| `panelUnlockCost` | 解锁功能界面所需瓶盖 |
| `hitRadius` | 点击命中半径（屏幕 px） |
| `flipDuration` | 抛瓶动画时长（ms） |
| `peakH` | 抛瓶峰值高度（世界单位） |
| `spinTurns` | 抛瓶旋转圈数 |
| `iso.scale` | 投影缩放（水平与深度） |
| `iso.ox` / `iso.oy` | 桌面中心在屏幕上的位置 |
| `charge.speed` | 蓄力指针摆动速度（phase/秒） |
| `charge.speedPerStreak` | 每 1 连击指针加速（phase/秒） |
| `charge.uprightCenter` / `charge.uprightHalf` | 直立区间中心 / 半宽 |
| `charge.invertedCenter` / `charge.invertedHalf` | 倒立区间默认中心（挂机/初始用，手动每次蓄力随机）/ 半宽 |
| `scoreBottom` / `scoreMouth` / `streakBonus` | 瓶盖奖励 |
| `manualMult` / `handMult` | 手动抛瓶收益倍率 / 挂机(手)抛瓶收益倍率 |
| `stabilityUpright` / `balanceInverted` / `godHandInverted` | 科技倒立/直立区间加成 |
| `autoThrowBase` / `autoThrowStep` | 手抛瓶基础间隔 / 频率每级缩减 |
| `handLuckBonus` | 提高手的几率每级区间加成 |
| `table` | 桌面世界尺寸（瓶子活动空间） |
| `debug` | 置为 `true` 显示瓶子索引与状态 |
