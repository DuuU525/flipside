# Flipside · P瓶子 — 科技树双方向拆分 + 重置功能（设计决策记录）

> 记录日期：2026-09-15
> 状态：**讨论阶段，未实施**（仅存档决策，不动代码）
> 关联：可玩性分析见 `docs/playability.md`，平衡数值见 `balance.md`

---

## 一、背景

现有科技树 23 节点 + 根，三大分支平铺（瓶子/成功率/手），全部可点满、无取舍——策略深度不足。
目标：拆成「手动技巧」与「自动挂机」两个方向，让玩家必须选择深耕路线。

---

## 二、方向拆分方案（三层结构）

### 中立基建（两方向共享，重置**不涉及**）

| 节点 | 理由 |
|---|---|
| 根节点 `_unlockTechTree` | 面板入口，必须保留 |
| `branchBottle` | 产能基础 |
| `expand`/`special`/`expandCap`/`jadeCraft` | 瓶数 = 两方向共同产能 |
| `hammerGlass`/`hammerGold`/`hammerJade` | 敲碎工具，通用 |
| `cdGlass`/`cdGold`/`cdJade` | 冷却对手动和挂机吞吐都有效 |

### 方向 A「手动技巧」（主动手点 + 技巧反馈）

现有 7 节点：`branchLuck` / `stability` / `balance` / `godhand` / `streak` / `streakReward` / `streakWindow`

### 方向 B「自动挂机」（挂机产能 + 丰富度）

现有 4 节点：`branchHand` / `unlockHand` / `handFreq` / `handLuck`

## 三、已确认决策（重置功能）

| # | 决策 | 内容 |
|---|---|---|
| 1 | 重置范围 | 只重置方向节点（A + B），中立基建保留 |
| 2 | 返还 | **直接清空，不返还**（推翻早期「打折返还」方案，制造真实切换成本）|
| 3 | 道具处理 | 清空方向产物道具（手 `hand`）；中立道具（瓶子/锤子）保留 |
| 4 | 不可重置 | 根节点保留；成就/里程碑不退回（一次性达成）|

## 三·二、科技点机制（2026-09-15 追加，推翻部分早期方案）

> 关键演进：从「瓶盖直接解锁科技」改为「**科技点**」经济。

| # | 决策 | 内容 |
|---|---|---|
| 1 | 科技点总量 | **固定 60 点**（硬上限，后续按需调整）|
| 2 | 科技点获取 | **瓶盖兑换**；兑换成本与**达成成就数量挂钩**（方向待定：成就越多越贵/越便宜）|
| 3 | 经济分离 | **不分离**——所有科技（含中立基建：瓶子/锤子/冷却）解锁与升级都消耗科技点，瓶盖仅用于兑换科技点 + 购买道具 |
| 4 | 重置语义 | **重置 = 重新分配方向节点已消耗的科技点 + 清空手**（科技点总数不减少，只重新投向）|

### 待澄清的矛盾/张力

1. **「只重置方向节点」vs「所有科技都花科技点」**：既然中立基建（瓶子/冷却）也消耗科技点，重置时是否也返还中立基建的科技点？若只返还方向节点，则中立基建的科技点永久锁定，玩家可能因早期「点错了瓶子」而无法优化。需明确：重置返还范围 = 仅方向节点，还是全部节点？
2. **「60 点」里中立基建占多少**：若瓶子/冷却/锤子也吃科技点，60 点要同时覆盖「产能基础 + 手动方向 + 挂机方向」，取舍会非常紧。需要精算：中立基建满配需要几点、A 方向满配几点、B 方向满配几点，三者之和是否 > 60（否则又回到「全都要」）。
3. **兑换成本与成就挂钩的方向**：成就越多 → 兑换越贵（通胀控制，后期瓶盖收益涨）还是越便宜（奖励老玩家）？

### 取舍机制（已接受）

**拆分方向 + 重置不返还 = 切换成本式取舍**，不引入硬互斥锁。
- 玩家可随时重置换路线，但投入的瓶盖全部打水漂，制造真实成本
- 两方向新增节点后科技点总需求 > 单轮可获取，自然只能深耕一条

## 三·三、科技点经济模型（2026-09-15 追加）

| # | 决策 | 内容 |
|---|---|---|
| 1 | 节点压缩 | 接受**解法 A**：多级节点压缩为一次性解锁（1 点）或 2 级封顶，避免「每级 1 点」导致 86 点爆表 |
| 2 | 取舍空间 | 制造**差异明显**的取舍缺口：基建 + A满 + B满 > 60，且缺口要大（玩家选择一边满，另一边显著残缺）|
| 3 | 兑换成本 | 兑换科技点消耗瓶盖，与「**第几个科技点**」挂钩（边际递增），成本与「该科技点对应技能的重要性」平衡 |
| 4 | 成就前置 | **成就数量作为解锁第 N 个科技点的前置条件**（递增），与兑换成本相互独立；**做成开关，默认关闭** |

### 已定模型（模型一：通用池 + 节点占点权重）

- 科技点为**通用池**：价格只随「累计购买序数 N」递增，与点哪个技能无关。
- 「技能重要性」体现在**节点占点数**：基础 1 点 / 中级 2-3 点 / 核心（终极节点）5 点。
- 三条曲线（已确认）：

| 曲线 | 公式 | 说明 |
|---|---|---|
| 兑换价格 | `100 × 1.15^(N-1)` | 几何递增；前 20 点 100~1400 盖，60 点总价约 130 万盖 |
| 成就前置 | `ceil(N / 5)` | 第 N 点需成就数；第 60 点需 12 成就；**做成开关，默认关闭** |
| 节点占点 | 基础 1 / 中级 2-3 / 核心 5 | 重要性 → 占点数 |

### 配置开关需求（待落地）

- 成就前置门槛做成**可开关配置**（CONFIG 布尔项），默认 `false`（关闭，不启用成就门槛）。
- 开启后：第 N 个科技点需先达成 `ceil(N/5)` 个成就才能兑换；关闭时无视成就数，仅看瓶盖。
- 开关影响 UI（成就页签/科技页签提示）与兑换校验逻辑。

## 三·四、节点占点分配（2026-09-15 追加）

- 取舍档位：**「明显」档**，且新增硬约束：**两方向满科技消耗科技点完全对称**。
- 核心等式：`60 = 基建(15) + 满方向(35) + 另一方向基础(10)`。

### 三层结构（最终占点，对称设计）

**中立基建 15 点**（两方向共享，压缩为解锁即满）：

| 节点组 | 占点 |
|---|---|
| 瓶子（expand 2 + special 3 + jade 3 + expandCap 2）| 10 |
| 三锤 | 3 |
| 三冷却 | 2 |

**方向基础科技 = 10 点**（每方向前 4 节点：入口 + 3 核心基础，是"能正常玩"的最低配置）

**方向满科技 = 35 点**（基础 10 + 进阶 25，两方向对称）

方向 A（倒立瓶 · 手动）进阶 25 点：

| 节点 | 占点 |
|---|---|
| godhand 神之一手 | 4 |
| streakReward 连击奖励 | 4 |
| streakWindow 连击时间 | 3 |
| pointerSlow 指针减速（新）| 3 |
| perfect 完美判定（新）| 4 |
| goldenLuck 金色概率+（新）| 3 |
| 倒立宗师（终极）| 4 |

方向 B（正立瓶 · 挂机）进阶 25 点：

| 节点 | 占点 |
|---|---|
| offline 离线收益（新）| 4 |
| handStreak 挂机连击（新）| 4 |
| handGolden 手幸运（新）| 3 |
| handSync 手速共享（新增补充节点）| 3 |

| handReport 挂机报告（新增）| 3 |
| 自动化工厂（终极）| 4 |

> 注：B 方向补齐为 11 节点（基础 4 + 进阶 7），与 A 完全对称；终极节点从 8 点调回 4 点与 A 对齐。
> **取消 `handAssign`（手分工）**：手与瓶子类型绑定有扩展性隐患（加新瓶子要加新手）。
> 新增 `autoHarvest`（自动收获）：特殊事件触发后，奖励（瓶盖/瓶子/锤子）需手动点取；本节点解锁「自动帮玩家收取事件奖励」。
> `handReport`（挂机报告）：回来弹本次挂机产出总结，挂机"有期待"。

### 事件掉落与收获机制（2026-09-15 追加）

- **奖励形态**：**桌面掉落物**（瓶盖/瓶子/锤子图标落在桌面，玩家点击收取）。
- **过期机制**：不是纯时间过期，而是**格子容量限制**——掉落物占据「收获格子」，最多保留 N 个；格子放满后新掉落进入**过期逻辑**（超时未收则消失/流失）。
- **格子可升级**：格子上限加入科技技能，**技能等级越高格子越多**。
- **事件触发不受终极限制**：没激活「自动化工厂」终极节点时也存在掉落事件，只是**掉落几率特别低**（呼应决策 3 的低几率全局可见）。

### 事件掉落与收获机制·定稿（2026-09-15）

| # | 决策 | 内容 |
|---|---|---|
| 1 | 格子归属 | **全局格子池**（所有掉落物共用 N 格，瓶盖/瓶子/锤子混放）|
| 2 | 满格逻辑 | 格子放满后**新掉落进入过期倒计时**（超时未收则消失），非直接不生成 |
| 3 | 格子科技 | **合并进 `autoHarvest`**（不新增独立节点，保持 11 节点对称）|
| 4 | 收获语义 | 格子作用是**减少未及时拾取的损失**；奖励仍需玩家**手动从格子拾取**，或在掉落物消失前拾取；**自动收获只对「过期过程中的掉落」生效**，格子里的掉落**不自动收取** |

### 收获机制完整语义（定稿）

```
掉落事件触发 → 掉落物落桌面
  ├─ 格子有空位 → 进格子，长期保留，玩家手动拾取
  └─ 格子满 → 进入过期倒计时(如 60s)
       ├─ 有 autoHarvest → 过期过程中自动收取(不流失)
       └─ 无 autoHarvest → 倒计时结束流失
```

- 自动收获 ≠ 自动收格子；只兜底「即将过期的掉落」。
- 玩家仍需回来手动拾取格子里的奖励（保留"收菜"互动感）。

### 约束验证

- **对称**：A满 = B满 = 35 点 ✅（11 节点、基础 4 + 进阶 7、终极节点均 4 点）
- **满一边 + 另一边基础**：15 + 35 + 10 = 60 ✅（满 A 时 B 只能点到基础；满 B 时 A 只能点到基础）
- **两边都满**：15 + 35 + 35 = 85 > 60 ❌（做不到，取舍成立）
- **终极节点**：各方向进阶末位，需方向点满才够，兑现「绝对优势」。

## 五、特殊玩法：Zoom 专注领域 + 桌面奇妙事件（2026-09-15 讨论）

> 设计目标：A 方向（手动）加「集中刺激」，B 方向（挂机）加「趣味性」，两者都用「低几率全局可见 + 满方向后强化」的漏斗设计，避免"没点满方向就彻底失去玩法"。

### 已拍板决策

| # | 决策 | 内容 |
|---|---|---|
| 1 | Zoom 触发 | **几率触发**：连击达到的**次数**与宗师技能等级**成正比**（没宗师技能时高连击也有触发，但几率极低）|
| 2 | Zoom 奖励 | 接受：挑战奖励 = 目标连击递增收益 × 系数（约 ×2），期望值不亏不赚 |
| 3 | 事件归属 | **不算专属**：几率极低（像 Zoom 一样），双修玩家不因没点满方向就彻底失去玩法；低几率让玩家看到另一方向可玩性，激发「点满→好奇→重置」循环 |
| 4 | 终极节点强化 | 参考 3，但**强调终极节点效果**：点满终极节点后，对应 Zoom/事件的**几率和奖励有明显区别**（大幅提升）|

### 核心机制（讨论稿）

**Zoom 专注领域（A）**：
- 触发：连击 ≥ 阈值（阈值 = 宗师技能等级决定，没宗师时也极高连击有极低几率）
- 状态：只高亮一个瓶子（无冷却），桌面与其他瓶暗淡 + 暂停（手也暂停/冻结计时）
- 挑战：连续抛该瓶冲连击上限；过程抛瓶成功无奖励，挑战成功有奖励，失败无奖励
- 可选：玩家可选择是否进入

**桌面奇妙事件（B）**：
- 触发：挂机产出时低几率刷新（双修/手动玩家也极低几率可见）
- 类型：挂机版金色瞬间 / 冰面融化 / 手速狂潮 / 神秘瓶盖（点取）等
- 平衡：事件收益 ≈ 挂机基线 +10~15%

### 触发保底（2026-09-15 新增）

- **目的**：玩家刚解锁/升级终极节点时，附加一个「虚拟几率」让玩家**尽快看到效果**，避免因低几率迟迟不触发而觉得"白点了"。
- **机制**：解锁/升级终极节点 → 附加虚拟几率（**非 100%**）→ 按「附加虚拟几率后的实际几率」正常判定 → 触发一次后**移除虚拟几率**，回到正常几率。
- **独立性**：A 终极（倒立宗师）保底 Zoom、B 终极（自动化工厂）保底事件，**各自独立**，互不影响。
- **兑现时机**：不强制必触发，就是按附加虚拟几率后的实际几率正常判定，触发即移除。

### 触发保底数值（2026-09-15 定稿）

- 虚拟几率建议值：**+30%**（非 100%）。解锁/升级终极节点后，实际触发几率 = 正常几率 + 30%，玩家通常 2~4 次判定内能触发；触发一次后移除 +30%，回到正常几率。
- 例：Zoom 无终极 0.4% → 点亮宗师 +30% = 30.4%（下一次抛瓶大概率触发）→ 触发后回落 0.4%（宗师加成另算）。

### 方向 A 候选新增（强化技巧性反馈）

1. **指针减速** `pointerSlow`（3 级）：蓄力指针速度 -8%/级，技巧有纵深
2. **完美判定** `perfect`（1 级）：直立区间中心再分窄「完美区」，命中奖励 ×1.5，给高手更高天花板
3. **金色瞬间概率+** `goldenLuck`（3 级）：金色瞬间触发概率 +0.15%/级，手动专属惊喜

### 方向 B 候选新增（增加挂机丰富度）

1. **离线收益** `offline`（3 级）：关页后按挂机配置产出，上限 +2h/级，解决毕业即流失
2. **挂机连击** `handStreak`（3 级）：手命中也积累少量连击（每级 +1 连击上限），打破「挂机不吃连击」但保持低于手动
3. **手幸运** `handGolden`（3 级）：手小概率触发金色瞬间（0.5%/级），挂机也有「回来收惊喜」期待
